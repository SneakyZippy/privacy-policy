⚡ App-Specific Privacy Policy

PowerTrace

Package ID: com.antigravity.battery
Android battery telemetry and idle drain diagnostics tool.

Effective Date: October 2026 Application Version: 1.0+ Developer: Felix Zöggeler (SneakyZippy) Source Code: GitHub Repository

Summary: PowerTrace is designed for transparency and diagnostics. All battery telemetry, alarms, and wakelock statistics remain entirely on your device in a local Room database. PowerTrace does not send diagnostic telemetry to external servers and contains zero trackers or advertisements.

1. Overview

PowerTrace provides technical insights into what drains your device's battery while the screen is idle. It captures snapshots of Android's internal diagnostic sources (such as dumpsys batterystats, dumpsys alarm, and dumpsys power) to compute deltas between user-defined recording sessions (e.g. overnight drain).

2. Information Collection and Telemetry Policy

PowerTrace is an offline diagnostic utility:

  • No External Telemetry: PowerTrace does not transmit your battery statistics, hardware identifiers, or usage logs to any remote server or third party.
  • No Analytics SDKs: There are no third-party trackers, crash telemetry suites (like Firebase or Crashlytics), or telemetry beacons embedded in the application.
  • No Accounts: You are not required to create an account or provide any personal information.
  • No Ads: PowerTrace is completely ad-free.

3. Diagnostic Permissions & Data Accessed

To perform deep battery diagnostics without requiring root privileges, PowerTrace requests specific advanced Android diagnostic permissions (typically granted via ADB by the user):

Permission / API Diagnostic Purpose Data Scope & Handling
BATTERY_STATS Reads system-level battery state, discharge rate, and per-app hardware energy attribution tables. Saved locally to the app's internal database for the duration of user-configured recording sessions. Never uploaded.
DUMP Accesses internal diagnostic service dumps (e.g., dumpsys alarm, dumpsys power) to pinpoint partial wakelocks and background wakeup alarms. Parsed locally in real-time to compute energy consumption metrics. Raw dump logs are discarded after delta calculation unless explicitly saved by the user.
PACKAGE_USAGE_STATS Correlates foreground app activity with background battery draw to identify idle drain culprits. Processed purely on-device for session delta reporting.
FOREGROUND_SERVICE Maintains an active background session during recording intervals (e.g., tracking idle loss while the screen is off). Displays a clear, non-dismissible ongoing notification in the status bar while recording is active.
QUERY_ALL_PACKAGES Resolves Android UIDs from the diagnostic dump to friendly package names and app icons. Used strictly for local UI display and name resolution.

4. Local Storage and Data Retention

All session recordings, baseline snapshots, and diagnostic metrics are stored exclusively in a local SQLite database (managed via Android Room) in the application's private sandbox directory:

  • You can delete individual recording sessions or clear the entire history at any time from within the app settings.
  • Uninstalling PowerTrace completely purges the local database and all associated diagnostic caches.

5. User-Initiated Data Export

PowerTrace includes a diagnostic export feature allowing users to export session snapshots as a JSON file or diagnostic checkin report for personal debugging or bug reports.

This export is 100% initiated by you using Android's system file picker or share sheet. PowerTrace never automatically uploads or shares exported reports. You maintain full ownership and control over where exported files are saved or sent.

6. Children's Privacy

PowerTrace does not collect any personal data from anyone, including children under 13.
