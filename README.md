## 🛡️ Core Principles Across All Apps

1. **Zero Tracking / Zero Analytics:** No Google Analytics, Firebase, Sentry, or third-party tracking SDKs.
2. **No Advertising:** Completely ad-free open-source software.
3. **No Accounts Required:** No logins, emails, passwords, or personal profile collections.
4. **Local-First & Offline Storage:** Settings and data are saved exclusively within the app's local sandbox on your device.
5. **Open Source Verification:** All apps are licensed under GPLv3 and public on GitHub for code audits.

---

## 🇩🇪 Zusammenfassung (Deutsch)

- **Lokale Daten:** Alle von unseren Apps verarbeiteten Daten (z. B. Einstellungen, Eingaben, Diagnosen) werden ausschließlich lokal auf Ihrem Endgerät gespeichert.
- **Keine Weitergabe:** Es erfolgt keinerlei Übertragung personenbezogener Daten an externe Server oder Dritte.
- **Keine Werbung & kein Tracking:** Die Apps nutzen keine Werbenetzwerke, Tracking-Tools oder Analysedienste.
- **Transparenz:** Vollständig Open Source unter GPLv3.
