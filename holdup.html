🧘 App-Specific Privacy Policy

HoldUp

Package ID: com.holdup.app
Mindful pause before doomscrolling for healthier digital habits.

Effective Date: October 2026 Application Version: 1.0+ Developer: SneakyZippy Source Code: GitHub Repository

Summary: HoldUp operates 100% offline on your device. The app does not request internet access (android.permission.INTERNET is not declared), collects no personal information, and contains zero advertising or tracking libraries.

1. Overview and Core Philosophy

HoldUp is an open-source digital wellbeing application designed to help users pause and reflect before opening distracting or habitual applications. Because your personal habits and screen time are intimate aspects of your digital life, HoldUp is engineered from the ground up to guarantee absolute privacy by running exclusively on your device.

2. Information Collection and Processing

HoldUp does not collect, transmit, sell, or share any personal information.

  • No Account Required: You never register, log in, or provide any email address or personal credentials.
  • No Telemetry or Analytics: The app does not include Firebase, Google Analytics, Sentry, Mixpanel, or any other telemetry library.
  • No Advertising: There are no advertisements or third-party tracking identifiers.
  • No Internet Permission: The application does not even request Android network access. It is physically impossible for the app to transmit data outside of your phone.

3. Device Permissions & How They Are Used

To perform its core functions of mindful intervention and habit coaching, HoldUp requests specific Android permissions. Each permission is used strictly locally:

Permission Purpose Data Treatment
AccessibilityService Detects when a user launches an application listed in the user's shield list in order to display the mindful pause screen. Also triggers standard system navigation (e.g., Back or Home action) when the user taps "Walk Away". Zero data logging. HoldUp only checks the foreground package name against your selected shielded apps. It never reads, inspects, captures, logs, or stores keystrokes, passwords, personal messages, or screen content.
PACKAGE_USAGE_STATS
(Usage Access)		 Allows the app to display today's accumulated screen time on the mindful reality check banner, providing context on daily usage. Read in real-time and displayed directly on screen. It is never logged or saved to persistent history.
SYSTEM_ALERT_WINDOW
(Display Over Other Apps)		 Enables the mindful friction overlay (breathing animation, reflection prompt, or personal anchor) to appear over a launched shielded application. Used solely to present the user interface. No background screen recording or screenshotting is performed.
POST_NOTIFICATIONS Sends a gentle reminder notification when a user-selected mindful usage session (5, 10, or 15 minutes) has expired. Scheduled and delivered locally on the device using Android's notification manager.
VIBRATE Powers rhythmic tactile haptic feedback during the guided breathing exercise. Local hardware actuation only.
QUERY_ALL_PACKAGES Allows the user to browse their installed applications in Settings to select which apps to shield or monitor. Queried locally to populate the settings list. The list of installed apps is never saved to external storage or sent off-device.
FOREGROUND_SERVICE
FOREGROUND_SERVICE_SPECIAL_USE		 Keeps the mindful pause timer active during unlocked sessions so the app can deliver the soft completion nudge when session time expires. Standard foreground service lifecycle. Operates strictly locally without data collection.

4. Local Data Storage

All application state is stored locally within Android's sandboxed private storage:

  • User Settings: Shielded app selections, pause duration preferences, and toggle states (stored via Android SharedPreferences / DataStore).
  • Mindful Points & Level: Points earned from tapping "Walk Away" or "Healthy Swap" are saved locally to track your focus tier.
  • Custom Reflections & Anchors: If you add custom quotes or choose an anchor image from your device, references are stored locally in your app's private directory.

Uninstalling the application immediately and permanently removes all stored data.

5. Accessibility Service Declaration (Google Play Policy Compliance)

HoldUp uses the Android AccessibilityService API strictly for its stated core functionality:

  • Detecting foreground window state changes to determine when a shielded application has been opened.
  • Performing the global Back or Home gesture when the user chooses to "Walk Away" from an app.
  • HoldUp does not use Accessibility APIs to collect personal data, monitor user typing, record audio, capture credentials, or modify system settings without user consent.

6. Children's Privacy

HoldUp does not collect any data whatsoever from any users, including children under 13 years of age.
